# مشاوي البلد

- `index.html`: الموقع كامل، والصور مدمجة داخله فيعمل وحده.
- `images/`: نسخ الصور الأصلية للاحتفاظ بها (الموقع لا يحتاجها).

## الرفع على GitHub Pages
1. فك الضغط، وارفع الملفات نفسها (index.html و images و .nojekyll و README.md) إلى أول المستودع، لا ملف الـ zip ولا المجلد الذي يحويها.
2. Settings ← Pages ← Deploy from a branch ← الفرع main والمجلد / (root) ← Save.
